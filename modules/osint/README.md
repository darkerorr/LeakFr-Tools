# OSINT — recherches en sources ouvertes

Outils de recherche passive ou de consultation de sources publiques. Les résultats ne prouvent ni l’identité d’une personne ni l’absence d’un compte. Respectez les conditions d’utilisation des sites interrogés.

![Aperçu de la catégorie OSINT](../../docs/screenshots/categories/osint.svg)

| Outil | Fonction | Aperçu |
|---|---|---|
| Recherche de pseudo | Vérifie des profils publics sur plusieurs plateformes. | ![Recherche de pseudo](../../docs/screenshots/modules/osint/recherche-de-pseudo.svg) |
| Analyse d’email | Contrôle le format, les MX et les éléments publics associés. | ![Analyse d’email](../../docs/screenshots/modules/osint/analyse-d-email.svg) |
| Wayback Machine | Recherche des captures archivées d’une URL. | ![Wayback](../../docs/screenshots/modules/osint/wayback-machine.svg) |
| Archive Change Watcher | Compare deux captures archivées, affiche ajouts/suppressions et exporte JSON ou Markdown. Une différence d’archive reste une observation historique, pas une preuve. | ![Archive Change Watcher](../../docs/screenshots/modules/osint/archive-change-watcher.svg) |
| Robots.txt & sitemap | Consulte les fichiers d’indexation publiés par un site. | ![Robots et sitemap](../../docs/screenshots/modules/osint/robots-txt-sitemap.svg) |
| Analyse d’URL | Décompose une URL et inspecte sa réponse/redirection. | ![Analyse URL](../../docs/screenshots/modules/osint/analyse-d-url.svg) |
| Google Dorks | Compose des requêtes de recherche avancées. | ![Dorks](../../docs/screenshots/modules/osint/google-dorks.svg) |
| Analyse téléphone | Affiche indicatif, pays et format normalisé quand possible. | ![Téléphone](../../docs/screenshots/modules/osint/analyse-telephone.svg) |
| Liens OSINT rapides | Prépare des liens de recherche publics à partir d’un pseudo. | ![Liens rapides](../../docs/screenshots/modules/osint/liens-osint-rapides.svg) |

## Utilisation

Depuis la racine, exécutez `python3 main.py`, choisissez **OSINT**, puis l’outil. Les services distants peuvent limiter ou modifier leurs réponses ; ne saisissez pas de données privées sans base légale.

Les visuels sont des aperçus statiques de l’écran/menu correspondant, pas des résultats de requêtes exécutées.
